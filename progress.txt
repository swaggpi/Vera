  Bugs found on device and fixed (each with a regression test, 74 tests green):
  1. Headlines rendered as "Headline in target language: Against Water Shortage Ban" — the model
     echoed the instruction as a label. localizedTitle now strips label preambles + trailing lines.
  2. English outlets were "translated" into English, so The Japan Times came back re-title-cased.
     localizedTitle now takes the outlet's own NewsSource.language as an exact skip signal.
  3. looksEnglish() counted "in"/"of" as English markers — both are just as common in German and
     Dutch, so German headlines skipped translation. Markers are now English-only.
  4. Story chat: asked "which countries landed on these beaches", the model replayed the article's
     own sentences and that was shown as the answer. A mostly-verbatim reply now counts as a miss.
  5. Story chat: "The article does not provide specific information about…" was not in the
     hardcoded miss list, so it was shown as a final answer instead of triggering a search. Miss
     detection is now a shape-matching regex; re-tested on device → the same question now searches
     and returns an attributed answer with the caveat line.
